						  KEY CONCEPTS
═══════════════════════════════════════════════════════════════════════════

ROOT CAUSE:
  Use-After-Free: SafeQueue destroyed while 3 threads still using it

THE BUG:
  delete queue → Threads still running → Access freed memory → CRASH

THE FIX:
  Signal → Wake → Join → Delete
  ↑ Proper shutdown sequence

EVIDENCE:
  • Crash address: 0x5555 (freed memory pattern)
  • 3 threads at same location
  • Uninitialized msec: 8742381210945547334
  • Corrupted deque internals

THE PATTERN (Universal for any thread-shared object):
  1️⃣  SIGNAL: Set flag to stop work
  2️⃣  WAKE:   Notify waiting threads
  3️⃣  JOIN:   Wait for threads to exit
  4️⃣  DELETE: Destroy the object
